# FlyMe2TheMoon

[English](README.md) | [简体中文](README.zh-CN.md) | 日本語

本プロジェクトは、独自開発の [ElysiaEngine](https://github.com/Akil0814/ElysiaEngine) を基盤とする **ステージ攻略型 2D 飛行ゲームの再現プロジェクト**です。**C++23、SDL3、Box2D、Lua** を使用しています。

miHoYo の初期作品『FlyMe2TheMoon』のステージデータ、ストーリースクリプト、映像・音声素材を参考に、飛行操作、物理ギミック、アイテム収集、ストーリー演出、メニューをデスクトップ向けに再実装しています。プレイヤーは下向きや斜め方向への噴射で推力を得て、重力と慣性を踏まえながら飛行ルートを調整し、障害物を避け、星と宝石を集めて、月を目指します。

本プロジェクトは、ゲーム開発の学習と原作の仕組みの研究のみを目的とした、**非公式の再現プロジェクト**です。

当初は **WDD（Wish-Driven Development、願い駆動開発）**を試すつもりでした。要件、エンジン、素材を AI に渡して、あとは自力でゲームを完成させてもらおう、というものです。しかし、トークン消費量が多すぎたことや、生成されたコードの品質と可読性に問題があったことから、結局は人の手を入れることになりました。

しかも、人の手を入れても Game Layer のコードは相当な部分がクソ読みにくいままです。（

## プロジェクトの内容

- **飛行と物理**：キーボード、マウス、ゲームパッドに対応し、連続的な推力調整、方向転換、重力、慣性、衝突を実装しています。ゲームパッドは実行中に接続・切断できます。
- **ステージとギミック**：全 60 ステージの地形・オブジェクトデータを取り込み、移動足場、回転ギミック、トゲ、風、ポータル、レーザー、発射装置、爆弾などの仕組みを実装しています。
- **ストーリーと演出**：Lua でステージイベント、会話、チュートリアル、カメラ移動を制御します。キャラクターのアクション、出現・死亡、転送、ゴール到達、アイテム収集のエフェクトも組み込んでいます。
- **収集と進行状況**：各ステージに三つの星があり、大小の宝石を区別しています。ステージスコア、ベストタイム、死亡回数、ストーリーフラグ、ローカル実績を記録し、ステージの依存関係に従って後続のコンテンツを解放します。
- **デスクトップ向け UI**：メインメニュー、ステージ選択、実績ギャラリー、設定、クレジットに加え、プレイ中の HUD、ポーズ、リザルト、新記録の通知を備えています。原作の素材を取り入れ、横画面のレイアウトに対応させています。
- **設定と音声**：ウィンドウモード、解像度、フレームレート、垂直同期、音量、言語を設定できます。BGM、ボイス、効果音も組み込んでいます。
- **開発ツール**：F2 パネルでデバッグ描画、フレームレート統計、時間倍率、ステージカメラを操作できます。自動テスト、入力リプレイ、アセット検査ツールも含まれています。

## クイックスタート

### 必要な環境

現在の主な開発・検証環境は **Windows x64** です。

- **C++23** に対応した MSVC と Windows SDK。Visual Studio の「C++ によるデスクトップ開発」ワークロードからインストールできます。
- **CMake 3.24** 以降。
- **Ninja**。
- **Python 3**：MSVC のコンパイラ出力の処理、アセット検査、一部の開発ツールに使用します。

サードパーティ依存ライブラリのソースコードは `thirdparty/` と `game/vendor/` に含まれています。通常の構成処理で依存ライブラリを追加ダウンロードする必要はありません。

### ビルドと実行

Visual Studio の **x64 Native Tools Command Prompt** を開き、プロジェクトのルートディレクトリに移動して、次のコマンドを順に実行します。

```bat
cmake -S . -B out/build/debug -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake --build out/build/debug --target FlyMe2TheMoon --parallel
out\build\debug\FlyMe2TheMoon.exe
```

読み込みが完了したら、いずれかのキーを押してメインメニューに進み、そこからステージ選択画面を開きます。

Visual Studio の「フォルダーを開く」で本プロジェクトを開き、`FlyMe2TheMoon` をスタートアップターゲットに設定することもできます。

MSVC の Debug ビルドでは `/Z7` による埋め込みデバッグ情報を使用します。Windows のビルドでは、実行ファイルと同じディレクトリに `SDL3.dll` が自動でコピーされます。

**実行時には `assets/` ディレクトリ全体を保持してください**。`assets/.elysia_root` と `assets/content_registry.json` も必要です。プログラムは親ディレクトリをたどってアセットを探すため、プロジェクトルートまたは上記のビルドディレクトリから起動できます。

- ログ：`logs/`
- ユーザー設定とローカルセーブデータ：`player_data/`

### ビルドオプション

CMake の構成コマンドの末尾に、必要なオプションを追加します。

| オプション | 既定値 | 説明 |
| --- | --- | --- |
| `ELYSIA_ENABLE_IMGUI` | `ON` | F2 開発パネルをコンパイルするかどうか。無効にしても、すべての画面でカーソルの自動非表示は機能します。 |
| `BUILD_TESTING` | `ON` | 自動テストのターゲットを生成するかどうか。 |
| `FLY_DEBUG_SYMBOLS` | `ON` | MSVC の最適化ビルドで、診断用のデバッグシンボルを保持します。 |

Release ではビルドディレクトリを分け、`CMAKE_BUILD_TYPE` を `Release` に設定することを推奨します。

## 操作方法

### キーボードとマウス

| 場面 | 操作 |
| --- | --- |
| メニュー | マウスでクリック。または方向キーで移動、Enter で決定、Esc で戻ります。 |
| 垂直方向の噴射 | W、↑、またはスペースを押し続けます。 |
| 斜め方向への飛行 | A / D または ← / → を押し続けると、左上 / 右上方向に推力を加えます。 |
| マウスでの飛行 | マウス左ボタンを押し続けると、キャラクターに対するポインターの位置と反対方向に推力を加えます。距離と角度によって推力が変わります。 |
| ポーズ / 再開 | Esc または P。プレイ中のポーズボタンをクリックすることもできます。 |
| 現在のステージをリトライ | R、またはポーズ / リザルトメニューでリトライを選択します。 |
| ストーリー | Enter またはマウス左ボタンで続きを表示します。Tab で既読のストーリーをスキップできますが、ストーリー側の待機時間やスキップ制限に従います。 |
| クレジット | ↑ / ↓ でスクロールし、スペースで自動スクロールを一時停止 / 再開します。 |

### ゲームパッド

SDL3 が認識できるゲームパッドに対応しています。初めて使用するときは、ゲームパッドのいずれかのボタンを押してメニュー操作を切り替えてください。以下のボタン名は Xbox 配列を基準としています。他のゲームパッドでは、同じ位置のボタンに対応します。

| 場面 | 操作 |
| --- | --- |
| メニュー、ポーズ、リザルト | 十字キーで移動、A で決定、B で戻ります。リザルトでは、A で現在選択中のボタンを実行します。 |
| 飛行 | 左スティックを上、左、右に倒すと噴射します。左右への傾きで飛行の傾斜角を調整できます。十字キーの ↑ / ← / → でも飛行できます。 |
| 垂直方向の噴射 | RT を徐々に押し込みます。同時に左スティックで傾斜角を調整できます。 |
| ポーズ / 再開 | B または Start でポーズメニューを開きます。ポーズメニューで B または Start を押すとゲームに戻ります。 |
| 現在のステージをリトライ | ポーズまたはリザルトメニューでリトライを選択し、A で決定します。 |
| ストーリー | A で続きを表示し、Y で既読のストーリーをスキップします。ストーリー側の待機時間やスキップ制限に従います。 |
| クレジット | 左スティックでスクロール、X で自動スクロールの一時停止 / 再開、B で戻ります。 |

左スティックと RT のデッドゾーンは、どちらも **20%** です。デッドゾーンを超えると推力が連続的に増加します。スティックを下に倒すだけでは噴射しません。ゲームパッドの A は決定とストーリーの続行に使用し、噴射には割り当てていません。X にステージのやり直しは割り当てていません。

キーボードの飛行入力はゲームパッドより優先されます。マウスボタンを押して噴射している間は、マウス入力が両方に優先します。飛行とストーリーの操作ヒントは、使用する入力デバイスに合わせて切り替わります。

カーソルはすべての画面で、動かさずに **2 秒**経過すると自動で非表示になり、実際に動かすとすぐに再表示されます。マウスボタンの押し続けや、キーボード・ゲームパッドの入力ではタイマーはリセットされません。ウィンドウがフォーカスを失ったとき、ポインターがウィンドウの外に出たとき、プログラムを終了したときにはカーソルが再表示されます。

## 開発とテスト

### F2 開発パネル

ImGui を有効にしたビルドでは、**F2** で開発パネルを表示 / 非表示にできます。メニューでもステージ内でも使用でき、ステージカメラの操作も同じパネルに統合されています。

- **デバッグ描画**：コライダー、接触点と法線、AABB、速度、姿勢履歴、ジョイントなどを確認できます。すべてのカテゴリーの選択、選択解除、既定値への復元が可能です。個々の描画プリミティブは、対応するシステムから送信される必要があります。
- **パフォーマンス統計**：FPS、フレーム時間、直近 120 フレームのフレーム時間グラフを表示します。右上の FPS 表示を有効にすると、F2 パネルを閉じても統計は表示され続けます。
- **時間制御**：シミュレーション速度を 0～2 倍に調整でき、一時停止と再開にも対応します。一時停止中もパネルは操作できます。
- **ステージカメラ**：ズームを 0.1～10 倍に調整でき、プリセット倍率とリセットボタンを備えています。HUD の大きさは変わらず、ステージに入り直すと既定の倍率に戻ります。

プロジェクトには自動テスト、入力リプレイ、アセット検査ツールも含まれています。具体的なテストターゲットとコマンドは、リポジトリの現在のビルド構成を参照してください。

## エンジンについて

本プロジェクトは **ElysiaEngine** を使用しています。ElysiaEngine は基盤となるランタイムと汎用的なエンジン機能を担当し、FlyMe2TheMoon のゲームロジックと Lua 関連の実装は Game Layer に置かれています。

技術ドキュメントとエンジンのソースコードについては、[ElysiaEngine](https://github.com/Akil0814/ElysiaEngine) を参照してください。
