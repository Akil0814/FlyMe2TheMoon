# 横屏地图边界补景

仅第 1、4、26、47 关启用视觉岩壁。其他 56 关不生成补景，开放式竖井和开阔地图保留原貌。

`assets/configs/fly/landscape_boundaries.json` 按关卡列出左右内缘与纵向范围。左右内缘均位于该关全部原始碰撞轮廓的外侧，补景使用相应 `suite` 的原 `Texture_040`，按原 HD 素材的半尺寸绘制。石块重叠以盖住透明边缘；末块裁切，不拉伸纹理。

`BoundaryRocks` 在原地形之前提交绘制，形成外围岩石衬底，原岩壁、植物、机关和角色继续覆盖其上。它只继承 `GameObject`，没有物理体、碰撞体或更新逻辑。原关卡 JSON、相机边界、出生点、机关、收集物和教学脚本均未修改。

以后只在逐关确认适合封闭岩壁后添加配置项；不要按章节或地图宽度自动启用。移除关卡配置项即可关闭该关补景。

本轮自动回放及截图保存在 `out/qa/boundary-rocks/`，`boundary-before-*` 为修改前，`boundary-final-*` 为最终画面。截图只覆盖各关开场附近，不代表四关完整路线的人工验收。

最终 Debug 构建通过；`fly_idle_visuals` 通过（78.50 秒），覆盖原 60 关地形贴图、镜像锚点及现有机关视觉。四条最终原生回放断言均通过，进程退出码均为 0，截图逐张检查完成。`comparison.png` 汇总四关修改前后的开场画面。
