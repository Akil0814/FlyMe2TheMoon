# 音效使用情况与原作差异审计

日期：2026-10-26。对象：`assets/audio/sounds`；对照仓库内 `reference/Fly2theMoon_1.1_ios_3.2` 的原作资源、60 关 Lua 和原程序 ARM 静态反汇编。

此报告保留接入前的使用统计。后续接入情况见 [audio-integration.md](audio-integration.md)。

## 结论与口径

- 当前目录有 **69 个 WAV，全部登记在 audio_manifest.json**，逐个比较 PCM 参数、帧数与采样数据哈希，全部与原作对应文件一致。
- **20 个有实际剧情播放引用，49 个未找到游戏播放引用**。这里“已使用”表示存在可到达的脚本调用及播放桥接代码，不代表本次逐关运行并试听。剧情是否播放还受通关状态、重试和跳过分支影响。
- 当前 60 个关卡 JSON 中的脚本与归档原 Lua 全文一致；共 78 处 sound.play，分布在 30 个关卡，解析后包含 22 个不同请求值：20 个可解析资源，以及缺失键 `44-1`、`53`。
- 原包有 **70 个 WAV 文件名、69 份不同 WAV 内容**；当前缺少文件名 `44-1.wav`，但其音频内容与已导入的 `42-1.wav` 相同。六首 CAF 属于背景音乐，不计入本次 69 个音效；它们均已有 WAV 导入文件。
- 缺口主要是**播放行为未接入**。49 个未使用文件中，40 个有原作机关、角色或 UI/结算方法证据；另外 9 个尚未确认原作实际调用。

播放入口：`game/scene/flight_scene.cpp:298` 将 Lua 参数中的 `-` 替换为 `_`，请求 `fly.voice_*`，归入 Extra 分组、默认单次播放。`voice_` 只是导入器统一起的键前缀，目录中包含环境、机关、UI 音效，不能全部称为人物语音。当前未发现其他游戏音效请求入口，也未发现前端为按钮配置声音。

## 两处确定的问题

1. **第 20 关请求 44-1，但清单和运行资源中不存在该键。** 文件实际位于 `reference/Fly2theMoon_1.1_ios_3.2/99_重复文件/组_001/Fly2theMoon.app/44-1.wav`，其原文件 SHA-256 与归档的 42-1 相同；PCM 也与当前 42-1 相同。导入器只遍历 `03_音频`，因此遗漏了重复区的这个文件名。可以补资源键别名 `fly.voice_44_1 -> fly/sounds/42-1.wav`，无需寻找或生成新音频。既有文档将其当作外部素材缺失的说法应以本次本地核查为准。
2. **第 31 关写的是 sound.play(55-2)，未加引号。** Lua 将它计算为数值 53，当前桥接随后请求 `fly.voice_53`，该键不存在。已有的 `53-1.wav` 是另一条资源，不能据编号直接代替。`55-2.wav` 文件虽然已经存在，但不会由此处播放。该写法来自原 Lua，当前导入未改动；若按疑似意图修正为 `sound.play("55-2")`，属于显式修正原脚本错误，不应称为补缺素材。
