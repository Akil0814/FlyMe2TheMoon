# 地图碰撞实现

`PhysicsWorld` 借用地图描述，并为占用单元格建立持久静态形状；每格保留坐标、过滤、材质和可选单向规则。绑定、脏区刷新与穿平台的操作见[地图碰撞指南](../../../user-guide/systems/tilemap-collision.md)。

## 邻接与单向支撑


过滤相同的相邻实心单元格会抑制共享内部接触面，暴露面仍阻挡。脏区域更新在下一步刷新邻接信息；单元格身份和材质仍彼此独立。

单向决策读取冻结的当前与先前形状边界、接触法线和已接受的支撑接触。先前边界保留接近方向，即使离散接触在越过表面后才出现，也能判断来向。已有支撑在穿透修正期间继续有效，微小的求解器速度反转不会立即关闭它。


替换或清空地图会使旧接触失效并回收原生标识。脏区更新只重建指定区域，不在每个固定步扫描整张地图。

Tile 继续生成矩形；原生轮廓由独立 Chain 资源表达，不自动从 Tile 数据提取。Chain 与 Tile 仍有不同身份：边段是 Collider，地图格是 Tile。
