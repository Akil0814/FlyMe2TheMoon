# 全局光标空闲隐藏

游戏的 `DevelopmentOverlay` 持有 `game::platform::IdleCursor`，借助应用已有的覆盖层宿主统一初始化、逐帧采样和关闭。应用启动时显示光标，鼠标静止满 2 秒隐藏，实际位移后显示并重新计时。启动页、主菜单、选关、设置、关卡、剧情、暂停、结算和 F2 沿用同一策略；持续按住鼠标、键盘或手柄不重置计时。页面切换和关卡重试保留计时及显隐状态，不由场景重置。

控制器使用 `SDL_GetTicksNS` 和物理鼠标状态，不依赖模拟 delta、时间倍率或路由输入。窗口失去键盘/鼠标焦点、最小化或指针移出客户区时显示并重置计时；客户区边界也会显式检查，避免拖拽捕获鼠标后在窗口外隐藏桌面光标。显隐操作仅在状态切换时提交，应用关闭时恢复光标。

游戏层 ImGui 适配器在光标因空闲隐藏时，围绕 SDL 后端的 `begin_frame` 临时设置 `ImGuiConfigFlags_NoMouseCursorChange`，随后恢复该位原值，防止后端每帧重新显示光标。移动唤醒后恢复普通 ImGui 光标形状管理。隐藏 F2 和 FPS 时仍采样光标，但不推进 ImGui 帧。关闭 `ELYSIA_ENABLE_IMGUI` 的构建同样运行光标策略。复用的是已有宿主接口，没有新增引擎公共接口或用户设置。

## 验证

- `fly_cursor_idle` 使用注入采样覆盖精确的 2 秒边界、微小移动、暂停时间、持续输入、焦点恢复、控制器重建和销毁；应用宿主测试验证开发界面全部隐藏时仍采样、输入不被捕获及关闭时恢复光标，可在启用和关闭 ImGui 时运行。
- `fly_gamepad_input` 使用真实场景验证开场、剧情、暂停、正常飞行、结算、主菜单、选关、设置以及退出/重试的显隐行为；采样时钟和位置可注入，模拟 delta 为零。
- `fly_development_overlay` 验证暂停的 F2 界面中反复隐藏/恢复、ImGui 不覆盖隐藏状态，以及原有 ConfigFlags 得到保留。

原生窗口检查尝试中，沙箱内定位未移动实际系统指针；Windows 自动化工具返回 `foreground window did not report a process id`，因此未完成真实桌面输入验收。自动化检查使用注入采样，不代替真实桌面输入验收。

可在交互桌面运行 `out/build/x64-Debug/game/fly_cursor_tests.exe --window-smoke`，点击测试窗口开始，静止等待隐藏，标题提示移动后在窗口内移动鼠标。该检查查询 Windows 实际光标句柄，并继续验证移出客户区、返回和最小化恢复；不会操作存档。
