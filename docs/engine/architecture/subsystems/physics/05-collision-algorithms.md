# 碰撞处理与空间查询

Box2D 负责宽阶段候选筛选、精确碰撞、连续碰撞和约束求解。Elysia 不维护第二套求解器，而是在其上提供引擎过滤、查询结果和玩法接入。

## 过滤与形状响应

引擎的类别、掩码和组过滤映射到原生形状。重叠形状作为传感器，忽略形状不创建原生碰撞形状；材质提供摩擦与恢复系数。

## 查询返回什么

射线与线段投射可以返回最近或全部命中。`overlap_shape`、`shape_cast` 和 `shape_cast_all` 支持矩形、圆形、胶囊和凸多边形，使用形状与世界姿态进行精确检测；扫掠只平移，不改变角度。起始重叠返回 `initial_overlap=true`、零距离和比例、查询起点及零法线，不提供接触流形。

结果使用引擎标识和世界单位（EU）。全部命中按比例与引擎目标排序，并移除重复形状命中。`CollisionQueryFilter` 支持类别／掩码／分组、忽略一个对象的全部碰撞体，以及排除传感器。同正分组的强制命中也适用于零掩码目标。重叠结果只标识形状，不额外生成穿透流形。

## 高速攻击如何使用

投射攻击形状后，按行进顺序处理命中，并在阻挡物处停止。传感器的 `Begin` 事件只表示离散采样接触，不能代替高速投射查询。Box2D 的原生 CCD 与接触语义见[模拟文档](https://box2d.org/documentation/md_simulation.html)。

Segment 是零厚度双面目标；Chain 是单面连接边，局部正面为 `(dy, -dx)`。Chain 的物理解算和射线遵循绕序，重叠与形状扫掠只做几何检测，不能用扫掠命中推断实体必然阻挡。查询源仍限四种有面积形状，忽略对象会排除其全部 Chain 子段。
