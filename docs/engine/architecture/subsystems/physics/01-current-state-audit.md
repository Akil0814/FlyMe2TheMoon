# 物理生命周期与当前限制

本文说明当前 Box2D 适配层的生命周期与使用边界。已提供静态、运动学和动态刚体、矩形、圆形、胶囊和凸多边形、质量策略、力与冲量、休眠、连续碰撞检测（CCD）、距离弹簧、旋转关节限位与马达、形状查询、地图几何及玩法事件转换。

## 句柄何时失效

句柄在一个物理世界中单调分配，重置也不复用。移除请求立即拒绝新的命令和状态查询；此前已接受的命令在安全点处理；关节修改会再次检查两端对象，失效时跳过。刚体移除同时使其关节失效。

适配层将包含代次的完整 Box2D 形状标识映射为引擎目标。销毁后，映射保留为失效记录，直到随后一轮事件提取完成。Gameplay 事件保存值，不借用 Box2D 或已销毁对象的内存。

## 接触与监听

接触失效只产生一次逻辑 `End`。同一引擎对象对的接触重建时，先产生 `End` 再产生 `Begin`；重置静默清空接触。监听器是借用对象，即使请求移除，也必须活过当前事件分发批次。

## 离散检测与连续检测

传感器检测步末重叠，不保证发现一个固定步内完全穿过的对象。高速攻击应使用显式形状投射，并在第一个阻挡命中处停止。子弹刚体改善物理 CCD，但不会把传感器事件变成连续检测。

单向平台使用模拟前冻结的几何与速度作出决策。Box2D 的预求解回调对高速连续接触存在限制，应按游戏实际速度验证平台行为。

## 形状、地图与尺度

公开形状为矩形、圆形、胶囊与最多八顶点的凸多边形，支持局部偏移及刚体旋转。另有 Static／Kinematic 专用 Segment 与独立 Chain 地形；凹形分解和布娃娃不在本轮范围；已有角色控制器仍锁定旋转。

地图的 `Block` 越界策略在有限地图周围建立边界墙，不表示任意远处都存在无限实心平面。地图安装上限为一百万个单元格。

可配置的世界单位比例用于单位换算，不能保证任意尺度都稳定。转换后的物理尺寸仍须符合 Box2D 的数值精度要求。

Chain 拥有复制的顶点和标签，每条实际边拥有 ColliderId。子段不可单独修改；移除 owner 和 Reset 回收整组，未提交创建在异常路径中回滚。开放链补首尾 ghost 以覆盖所有输入边，闭合链保留输入绕序。
