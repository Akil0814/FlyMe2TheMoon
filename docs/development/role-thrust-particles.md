# 游戏层喷射粒子

喷射使用 `game/particles/ParticleEmitter` 在 CPU 上更新粒子，再提交已有的引擎渲染命令。没有新增引擎粒子服务。粒子是唯一的角色喷射表现。

## 原作依据

只读分析本地原程序的 `RoleView.createParticle`（0xCF59C）和 `updateParticleByPushForce:fireAngleDegrees:`（0xD0258），未执行原程序：

- 容量 60，寿命 0.2 ± 0.02 秒，发射率 300 个/秒。
- 速度 250 ± 25，角度随机散布 ±9°，原坐标重力 (0,-100)，转换到当前向下 Y 坐标为 (0,100)。径向和切向加速度均为零。
- 起始尺寸为 `clamp(force,2,32)`，结束尺寸为 `clamp(force/2,1,16)`，结束尺寸随机量 ±15，最终尺寸不小于零。
- 纹理来自原作 `fire.png`，原文件直接复制为 `assets/textures/role_fire.png`，未重绘。初始 RGB 为 (128,158,182)，结束 RGB 为黑色。

原粒子使用预乘 RGB 和零粒子 alpha，混合因子为 ONE / ONE_MINUS_SRC_ALPHA。本实现折算为独立纹理的 SDL 加法混合和随寿命衰减的 alpha。尺寸以当前输入推力乘最大推力 28 计算；尚未逐帧对照原版画面，也未将功率限制后的实际施力幅度反馈到尺寸，因此不宣称像素级还原。

## 更新与生命周期

发射器支持速率累积、寿命与速度随机量、重力、尺寸和颜色插值、固定种子以及容量限制。粒子出生后保持世界坐标，移动中的发射点按前后位置插值。更新只在常规更新中进行；渲染提交不会推进粒子。大时间步只处理最近最多一个容量的出生数量，避免无界补发。

喷射继续沿用左右动画对应的脚部挂点。松开喷射、暂停、死亡、隐藏角色及月亮/传送演出会隐藏粒子；停止状态更新时会清空发射历史，恢复后不会补发暂停期间的粒子。粒子属于视觉表现，不参与物理碰撞。

## 验证

Debug 主程序和测试目标构建通过。`fly_particles`、`fly_gamepad_input`、`fly_idle_visuals` 均通过，覆盖发射率、时间步拆分、重力、寿命、世界坐标、容量、大时间步、随机种子、颜色衰减、脚部挂点与暂停输入释放。

软件渲染预览为 `out/qa/role-particles-preview.bmp`；每排依次是直线、左飞、右飞和弱推力粒子，上排为持续喷射，下排为刚开始喷射。尚未进行实体手柄游玩验收或原版逐帧画面对照。
