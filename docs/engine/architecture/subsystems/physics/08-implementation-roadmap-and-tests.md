# 物理迁移的历史验证与性能

本文保留 Box2D 迁移时的验收和微基准结果，不代表当前工作树的测试状态。原记录未提供测量日期，下面保留其环境、范围和数值，不补造时间。当前测试运行方法见[测试指南](../../../contributing/testing.md)。

## 历史验收范围

迁移用公开行为测试替换了旧的算法专用测试，覆盖：

- 单位换算、尺度一致性、密度、显式质量和惯量；
- 固定步回调、创建与移除、传送顺序和静默重置；
- 传感器 End 生命周期与解绑后的 Gameplay 路由；
- 四种形状的注册、质量／惯量、CCD、旋转查询和 4×4 形状查询组合，以及单向平台和地图更新；
- 距离与转轴关节的运行时弹簧、限位、电机、唤醒、延迟更新、失效与异常回滚；
- 逐分配点的注册／所有权失败注入，避免依赖 Debug 和 Release 不同的固定分配次数；
- 实际场景注册、输入锁存、伤害与渲染插值。

历史 Debug 构建通过全部 84 个 CTest 目标。地图回归覆盖双向跨接缝、脏更新后的暴露面、跨两个单向支撑休眠、穿过全部支撑再落回平台；Gameplay 测试也覆盖多支撑穿过辅助方法。

Box2D 实验场通过 SDL 软件渲染冒烟测试，并检查了生成的几何预览。原记录未完成实际窗口交互和移动手感验收。

## 如何复现计时探针

以 Release 配置 `ELYSIA_BUILD_PHYSICS_BENCHMARK=ON`，运行 `physics_benchmark`。探针分别测量 100 和 500 个分离的运动矩形，预热 200 步，再测量 1000 个 60 Hz 固定步。关闭调试捕获与休眠，记录整个 Elysia 推进调用的中位数和 P95。

## 历史基准结果

迁移前的独立探针使用 `/O2 /DNDEBUG /MD`：

| 刚体数 | 中位数 µs | P95 µs |
| --- | ---: | ---: |
| 100 | 22.0 | 34.7 |
| 500 | 185.1 | 225.6 |

同一主机上，Box2D 后端的 Release 探针结果为：

| 刚体数 | 中位数 µs | P95 µs |
| --- | ---: | ---: |
| 100 | 29.0 | 42.2 |
| 500 | 190.9 | 205.9 |

这些结果来自最终适配层与归档原生实现的顺序测量，均包含引擎事件提取与状态同步。100 个刚体的中位数更高；500 个刚体的中位数相近，P95 更低。该记录不能证明引擎普遍加速。

新增能力探针单独测量 50 个旋转矩形和五个距离弹簧：

| 是否启用休眠 | 中位数 µs | P95 µs |
| --- | ---: | ---: |
| 否 | 97.3 | 164.2 |
| 是 | 108.5 | 136.1 |

启用休眠只是世界配置，不表示每个刚体都已休眠。该场景没有对应的旧后端基线。这是稀疏刚体微基准，不是堆叠基准，也不代表整个引擎的性能；运行负载和机器状态都会影响结果。

## 第二阶段验证入口

`physics_stage2_tests` 覆盖地形、目标位姿和新增关节；`physics_exception_safety_chain`／`chain_deferred`／`stage2_joints` 覆盖逐分配点回滚。新增八个共享场景同时用于行为测试与 `box2d_lab_*_scene` 的离屏绘制和输入回归。Debug、Release、关闭 ImGui 三种配置均运行物理标签及完整 CTest。离屏图像检查与实际窗口验收分开记录，既有非物理失败单独报告。

基准新增 Chain 地形、逐步目标、六种关节和胶囊扫掠的混合负载，仍先预热 200 步再采样 1000 步；该负载没有旧版本性能基线。
