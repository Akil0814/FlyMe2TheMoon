# 激光草的分层显示

`DynamicObject_114` 现在绘制底座、可转动的两段头部、双层光束、束身闪电、命中闪光和世界空间粒子。可见部分共享物理对象的插值姿态，遮挡距离与伤害仍由原有射线查询计算。

## 原作证据与素材

只读取本地参考文件，不执行原程序。`LaserBeam.initSprites`（0xb6fa4）创建 S01 两个独立部件及 S02 两层光束；`updateAnimation:`（0xb4c14）按瞄准角查表，调整部件位置和旋转。它们不是轮播帧。

| 素材 | 用途与还原方式 |
|---|---|
| 根图 | 固定底座，保持常态显示 |
| S01/002、S01/001 | 两段头部，分别用 0x1a0844、0x1a0b20 的 61 项位置/旋转表，锚点为原 Y-up 的左下角；按原 3°步长取样，与炮口表共用角度含义 |
| S02/002 | 炮口处 9 单位长的光束前段 |
| S02/001 | 从炮口前方 9 单位处延伸至命中点，宽度保留原图；极短光束裁剪前段，避免负长度 |
| S03 四帧 | 光束周围的闪电，约 12 Hz 切换到不同帧；仅覆盖前方最多约 53 单位，不把闪电无限拉长 |
| S04 二十帧 | 命中点的闪光，按原 60 Hz 节奏循环，逻辑尺寸 32×32 |
| stars.png | `initParticle`（0xb69e0）使用的独立粒子图；36 粒容量、寿命约 0.2±0.02 秒、180 粒/秒、速度 50±5、Y-up 发射角 270±90°、重力 -100、尺寸从 4 到 8±8 |

头部与光束的深度沿用原分层：光束与闪电在后，头部在底座之下，命中闪光在前。`initLaserEndEffect`（0xb6e30）读取全部二十帧。图集帧裁剪、旋转锚点和原生像素到逻辑单位的 0.5 比例均通过公开 RenderCommand 提交。

## 游戏层接入与边界

`LaserVisual` 管理贴图、闪电帧、命中动画与有限数量的星点粒子；`Entity` 提供当前瞄准角、射线长度和是否命中实体。未命中物体时不生成远端命中特效，停射后已有粒子会自行消失。粒子保留发射时的世界坐标，不跟随已转走的载体。

头部姿态与炮口数据由 `import_laser_visual.py` 从原程序提取；粒子图从参考包已解码的 PNG 复制。主导入器也包含该独立图片，重导入不会丢失资源注册。

闪电切换与粒子使用按对象 ID 初始化的可重复随机序列；粒子的淡出和桌面帧率下的时间推进属于当前游戏实现，不宣称复现原 Cocos 随机序列或逐像素混合结果。现有激光瞄准、自动摆动、开启范围、射线遮挡、伤害与音效策略未在本次调整，原头部初始朝向在逻辑启动后与现有瞄准器同步。

## 验证

`fly_idle_visuals` 检查常态三层拼接、真实 S01/S02 贴图、炮口前段和光束连接、遮挡长度、全部二十帧命中动画、闪电切换、粒子生成与收尾、极短光束，以及载体旋转后世界粒子不被带走。真实 PhysicsWorld 检查墙体遮挡玩家、去掉墙体后正常命中、无实体时不产生虚假命中。

软件绘制总览为 `out/qa/laser-visual-preview.bmp`：上排常态，下排发射，三列为向左、向上、向右。可复用的原生回放输入为 `game/testing/level9-laser-visual.json`。实际验证记录见 `original-flight-research.md`。
