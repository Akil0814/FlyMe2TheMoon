# 实施计划

1. **调查与构建基线（进行中）**：全量文件/关卡/脚本/动画/触发器清点；引擎保护哈希；Release 骨架构建和原启动流程图形测试。
2. **可玩垂直切片**：数据导入器转换原地图和资源到游戏专用清单；第 1–3 关角色推进、相机、地形、星星/水晶/月亮、死亡重试。先实际操作与截图校准，再扩展。
3. **全机关覆盖**：移动平台/尖刺/转轴/风/投射物/激光/传送门/载体/区域事件；逐类编译、运行测试。参数从原 Info 读取，缺失默认值注明推断。
4. **全内容与流程**：60 关、四章选关和原依赖、三语言剧情、镜头及教程、菜单/设置/结算、成就、持久化；保留原始脚本条件，不将所有对话平铺播放。
5. **验证与交付**：Release 打包；每关进入/游玩/失败/通关测试，记录输入或测试路径；存档重启/损坏恢复检查；资源与引擎哈希核对；独立文件夹启动；最终验收、差异和开发体验报告。

## Game Layer 模块

- `content`：只读规范化关卡/精灵/剧情数据、严格校验和导入记录。
- `gameplay`：玩家飞行、原作实体行为与关卡状态。底层碰撞、渲染、输入路由使用引擎。
- `scene`：主菜单、选关、关卡、剧情/结算；Scene 路由管理所有权。
- `progress`：进度、原依赖图、成就规则、SaveService 业务编码。
- `tools`：离线导入、构建、回归与打包工具；不能改变正式游戏的过关规则。

## 验证原则

编译通过不等于可玩。自动注入合法输入的通关与直接构造状态的规则单测分别记账；传送测试不能冒充实际飞行通关。未验证的关卡保持“已实现待验证”。不删测试、不修改原始数据以规避失败。测试存档与玩家存档隔离。
