Ready for the moon? Start the full game below.

v1.0.1

Click the game to focus. Space / W / Up: thrust; A / D: steer. Hold the mouse below the character to fly. P: pause; R: retry; Esc: back. Supported gamepads can also be used.

Desktop browsers with WebGL 2 are required. Click the game or press a key to enable audio. Saves belong to this browser and website; clearing site data removes them.
