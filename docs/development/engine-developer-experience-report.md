# ElysiaEngine 开发体验（持续更新）

以下仅记录实际调查发现，后续补充编译和运行证据。

2026-10-25 局外 UI 接入补充：

- `set_style_overrides` 替换整份覆盖记录。选中标签只设置颜色时，曾丢失构造时设置的圆角。读取当前 `style_overrides()` 后修改颜色并提交，可同时保留圆角、悬停与按下样式；已补章节及成就分页测试。
- 公开 `SettingsPanel`、`UserConfigService` 足以承载带游戏背景的设置 Scene。游戏侧复用现有控件、事务保存与回滚结果，没有修改内置 SettingsScene；实际保存、返回均有 SDL 输入回放。
- UI 纹理切成窄四边形再作非整数缩放时，实机出现了细竖线。改为绘制完整纹理四边形，配合公开的 `clip_rect` 做整数像素渐隐区域后消除。该修复完全位于 Game Layer。
- 示例资源清理后，启动验证准确指出 additional module、动画特效清单中的残留引用。游戏清单同步清理后恢复加载；未绕过引擎验证。

- 文档明确划分 Scene 与 GameObject 生命周期，尤其标出不能同步添加对象的更新阶段，有利于避免所有权错误。
- 资源、音频、存档、UI 均有公开服务和示例，可避免重复实现底层系统。
- 源数据使用任意多边形轮廓；初版公开 Collider 只支持 AABB 和圆，因此曾使用薄矩形边。2026-10-24 用户提供的新版已增加凸多边形、胶囊、Segment/Chain；游戏已迁移到原生线段并接入原版复合角色形状，旧限制已解除。
- 文档中一些示例仍引用 game/showcase 与 example_game_module，当前游戏骨架不含这些文件；使用指南中的独立完整例子仍可参考。
- Windows MSVC 的中文 `/showIncludes` 与当前 CMake/Ninja 的编码组合使依赖前缀乱码，导致全部头文件依赖丢失。这是实际构建工具链问题，不归因于引擎 API。仅设置 `VSLANG=1033` 未能解决；现用 Game Layer Python 编译器启动器规范化 include 前缀，`ninja -t deps` 已从 0 恢复为 182 条示例依赖；后续头文件修改会重编译调用方。
- Scene 暂停默认也暂停 CameraRuntime 的跟随与待执行 snap。带暂停对白的场景必须明确设置 `CameraSceneConfig.advance_when_paused=true`，否则开场镜头停在尚未跟随角色的位置。
- 资源点分键不接受连字符；原作语音 `106-1.wav` 需要资源键适配为 `fly.voice_106_1`，文件名本身可保留。引擎启动错误准确指出清单位置，因此没有修改引擎验证规则。
- UI 默认内置字体按当前语言选字库；在英语环境显示硬编码中文会出现方框。游戏使用已有 OFL 项目字体，并让默认拉丁字体选择包含拉丁字符的简中字体以显示混合文本，后续仍需完整语言切换验证。


2026-10-24 更新后的实际接入经验：

- `CollisionQueryFilter` 把碰撞位、整对象排除和传感器开关集中起来，弹丸现在可以直接忽略自身所有形状。`shape_cast_all` 能覆盖弹丸半径，原先线段测试会漏掉擦边情况。
- `set_target_transform` 内置角度最短路径处理，替换了游戏层载体的手工角速度计算；270°/-90° 等价姿态的回归测试保留。
- 关节设置移入 `settings`；迁移成本集中在 Game Layer 的少量初始化点。新的文档对 EU 力/扭矩单位、目标姿态生命周期、无效参数返回行为有明确说明。
- 新版迁移编译、4 项 CTest、第 4/7/9/13 关运行，以及首关三星通关均已实际执行。没有为迁移修改引擎实现。原版多形状质量分配需要显式将上身密度设为 0，以保留底部圆形重心；默认密度不能无条件沿用。


2026-10-25 回执 006 接入：

- `MassProperties` 的 DensityMass / ExplicitMass / BodyMassData 区分默认密度、比例缩放惯量、独立质量数据。七根原版转杆现在可只替换质量、保留初始惯量，公开状态能够直接验证 COM 与惯量，无需访问 Box2D。Release 与 5 项 CTest 通过，三个受影响关卡采样确认。
- 接入范围仅 Game Layer。独立质量字段解决了原还原差异；第 30 关残留出生激光死亡是游戏还原调查项，不能以引擎回执测试代替关卡验收。
- CollisionFilter.group 可表达附属物和同载体之间不互撞；实际消除了第 30 关转杆被自身附属物卡住的问题，角速度恢复到配置值。
