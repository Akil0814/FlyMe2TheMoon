# 引擎开发路线图

本文记录已实现能力与后续方向，方便了解引擎的功能边界。这里不承诺完成时间或接口稳定性；实际使用方法见使用指南，实现细节见架构文档。

## 计划中的能力

- Shader 特效系统。
- 粒子系统。
- [网络联机支持](player-host-networking-and-input-design.md)。ENet 目前是传输层依赖，网络会话与状态复制尚未实现。

## 仍需评估的方向

多线程物理模拟、编辑器集成和纹理句柄抽象仍需评估。

## 已实现的基础能力

- 场景生命周期、缓存重入、安全修改阶段与异常恢复。
- 本地输入路由、键盘分区、控制器与固定步命令交付。
- 保留模式 UI，以及世界文字、数值条和被动气泡。
- SDL3 迁移与 Box2D 集成。
- 相机跟随、镜头运动与槽位切换混合。
- 内置与项目资源管理、运行时配置、类型化存档及失败恢复。
- 项目音频、动画与注册特效定义。
- 模块演示、自动化测试与可选开发覆盖层。

当前子系统入口见[架构索引](../architecture/README.md)。
