# Elysia Engine 开发者文档

[English](../en/README.md) | **简体中文**

本文是中文文档的总入口。无论你准备使用引擎开发游戏，还是修改引擎实现，都可以先按阅读目的选择相应指南。

## 使用引擎开发游戏

[使用指南](user-guide/README.md)介绍构建运行、游戏模块接入、场景与对象，以及各子系统的公开接口。第一次接触引擎时，建议先阅读[核心概念](user-guide/core_concepts.md)，理解对象由谁持有、代码何时执行和不同坐标的含义。

## 查询接口与配置格式

[接口与格式参考](reference/README.md)集中记录 UI、音频、输入与控制、物理和资源 JSON 契约。使用指南按任务组织步骤与示例；参考文档供查询完整调用规则。

## 理解与修改引擎

[架构与模块设计](architecture/README.md)解释当前实现中的职责划分、依赖关系、运行流程和生命周期。需要修改某个子系统时，先确认它与场景、资源和游戏层的边界，再阅读对应源码。

[开发与贡献指南](contributing/README.md)说明编码规范、测试方法和文档维护约定。它面向准备提交代码或文档变更的开发者。

## 查看设计与计划

[设计文档与开发路线](design/README.md)记录未来能力和历史设计讨论。这里的提案不等于引擎已提供的接口；使用现有功能时，应以使用指南、当前架构和源码为准。
