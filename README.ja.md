# FlyMe2TheMoon

[English](README.md) | [简体中文](README.zh-CN.md) | 日本語

本プロジェクトは、独自開発の [ElysiaEngine](https://github.com/Akil0814/ElysiaEngine) を基盤とする **ステージ攻略型 2D 飛行ゲームの再現プロジェクト**です。**C++23、SDL3、Box2D、Lua** を使用しています。

miHoYo の初期作品『FlyMe2TheMoon』のステージデータ、ストーリースクリプト、映像・音声素材を参考に、飛行操作、物理ギミック、アイテム収集、ストーリー演出、メニューを Android 向けに再実装しています。プレイヤーは下向きや斜め方向への噴射で推力を得て、重力と慣性を踏まえながら飛行ルートを調整し、障害物を避け、星と宝石を集めて、月を目指します。

本プロジェクトは、ゲーム開発の学習と原作の仕組みの研究のみを目的とした、**非公式の再現プロジェクト**です。

当初は **WDD（Wish-Driven Development、願い駆動開発）**を試すつもりでした。要件、エンジン、素材を AI に渡して、あとは自力でゲームを完成させてもらおう、というものです。しかし、トークン消費量が多すぎたことや、生成されたコードの品質と可読性に問題があったことから、結局は人の手を入れることになりました。

## プロジェクトの内容

- **飛行と物理**：タッチ操作による推力調整、方向転換、重力、慣性、衝突を実装しています。
- **ステージとギミック**：全 60 ステージの地形・オブジェクトデータを取り込み、移動足場、回転ギミック、トゲ、風、ポータル、レーザー、発射装置、爆弾などの仕組みを実装しています。
- **ストーリーと演出**：Lua でステージイベント、会話、チュートリアル、カメラ移動を制御します。キャラクターのアクション、出現・死亡、転送、ゴール到達、アイテム収集のエフェクトも組み込んでいます。
- **収集と進行状況**：各ステージに三つの星があり、大小の宝石を区別しています。ステージスコア、ベストタイム、死亡回数、ストーリーフラグ、ローカル実績を記録し、ステージの依存関係に従って後続のコンテンツを解放します。
- **横画面 UI**：メインメニュー、ステージ選択、実績ギャラリー、設定、クレジットに加え、プレイ中の HUD、ポーズ、リザルト、新記録の通知を備えています。
- **設定と音声**：フレームレート、垂直同期、音量、言語を設定できます。BGM、ボイス、効果音も組み込んでいます。
- **開発ツール**：F2 パネルでデバッグ描画、フレームレート統計、時間倍率、ステージカメラを操作できます。自動テスト、入力リプレイ、アセット検査ツールも含まれています。

## Android ビルドと操作

このブランチは **Android 8.0 以降の ARM64 スマートフォン**を対象とし、オフラインで動作する Debug APK と署名済み Release APK を生成します。PC ビルドは保守しません。

PowerShell 7 と JDK 21 を用意し、プロジェクトルートで実行します。

```powershell
./android/tools/setup-android.ps1 -AcceptLicenses
./android/tools/new-release-key.ps1
./android/tools/test-host.ps1
./android/tools/build-android.ps1 -Variant All
```

署名キーは初回のみ生成し、Git 外の署名ディレクトリを安全にバックアップしてください。更新には同じキーを使います。APK とチェックサムは `out/android/dist/` に出力されます。

画面を押し続けるとその位置に応じて推力が発生し、離すと停止します。メニューはタッチで操作します。Android の戻る操作で一時停止やメニューの移動、終了確認を行えます。バックグラウンドから戻った際は、手動でゲームを再開します。

すべてのリソースを APK に同梱し、初回起動時に約 145 MiB をアプリ内部に展開します。セーブデータは別の場所に保存されます。アンインストールやデータ消去でセーブは削除されます。F2 パネルと PC 向けウィンドウ設定は無効です。

詳細は [Android ビルド・署名・検証ガイド（中国語）](docs/development/android.md)を参照してください。

## エンジンについて

本プロジェクトは **ElysiaEngine** を使用しています。ElysiaEngine は基盤となるランタイムと汎用的なエンジン機能を担当し、FlyMe2TheMoon のゲームロジックと Lua 関連の実装は Game Layer に置かれています。

技術ドキュメントとエンジンのソースコードについては、[ElysiaEngine](https://github.com/Akil0814/ElysiaEngine) を参照してください。
